🍅 POMODORO TIMER

A simple and responsive **Pomodoro Timer** built using **HTML, CSS, and JavaScript**. This project helps users improve productivity by following the Pomodoro Technique, where work sessions are followed by short breaks.

🚀 Features

- ⏱️ 25-minute countdown timer
- ▶️ Start timer
- ⏸️ Pause timer
- 🔄 Reset timer
- 🎨 Modern and responsive user interface
- 📢 Alert when the timer reaches zero

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
